# Threshold Studio World Structure

This document defines the full world system for Hub Mode and site-wide exploration.

## A. Pedal System (Inner Chambers)

Pedals are the inner chambers arranged around the Hub. Each pedal has a mood, interaction grammar, and reward logic.

### Pedal 1: Threshold Pedal
- Core tone: Entry, orientation, consent to stay.
- Visual language: Soft ring, low glow, minimal drift.
- Primary interaction: Hover to reveal orientation lines.
- Reward: Unlocks first branch paths and map hints.

### Pedal 2: Breath Pedal
- Core tone: Pace, stillness, recovery.
- Visual language: Slow opacity breathing, long fades.
- Primary interaction: Long-hover events.
- Reward: Seasonal lore and patience glyphs.

### Pedal 3: Fracture Pedal
- Core tone: Break, reframe, adaptation.
- Visual language: Flicker edges, split events, brief jitter.
- Primary interaction: Click and double-click chain.
- Reward: Rare glyph channel unlock.

### Pedal 4: Echo Pedal
- Core tone: Memory, resonance, return signal.
- Visual language: Trails, repeats, mirrored drift vectors.
- Primary interaction: Revisits and sequence completion.
- Reward: Recurring poem fragments and return variants.

### Pedal 5: Lantern Pedal
- Core tone: Hospitality in darkness.
- Visual language: Warm center, shadow falloff, focused shimmer.
- Primary interaction: Cursor proximity and hold.
- Reward: Hidden gallery access and branch stabilization.

### Pedal 6: Compost Pedal
- Core tone: Transformation over disposal.
- Visual language: Slow dark-to-light pulses and layered roots.
- Primary interaction: Multi-step contributions (hover + click + revisit).
- Reward: Secret seed states and branch rewrites.

## B. Galleries (Hidden Curated Spaces)

Galleries are unlockable rooms layered over normal pages. They are discovered by contribution thresholds.

### Gallery: Root Archive
- Unlock: Hover 5 unique glyphs and revisit once.
- Content: Foundational vows, first fragments, origin lines.
- Placement: Links from Ethos and House and Garden.

### Gallery: Lantern Vault
- Unlock: Long-hover 3 glyphs in one session.
- Content: Quiet lore cards, care protocols, return instructions.
- Placement: Entry from House and Garden and Hub overlay.

### Gallery: Storm Cabinet
- Unlock: Double-click 2 glyphs and trigger one rare event.
- Content: Fracture myths, refusal stories, remapped paths.
- Placement: Dynamic branch from Mythology.

### Gallery: Seasonal Alcove
- Unlock: Trigger one seasonal reveal in all four seasons.
- Content: Fog, ocean, storm, soil fragments with unique visuals.
- Placement: Learning Wheel branch layer.

## C. Easter Eggs (Seeds, Stars, Vines, Hum Lines)

### Seeds
- Small node glyphs that pulse on hover/click.
- Behavior: Increment hidden counters and reveal micro-lines.

### Stars
- Rare bright shimmer events in Hub constellation.
- Behavior: Temporary state where one glyph becomes a guide.

### Vines
- Curved underlay motifs with hover shimmer.
- Behavior: Act as non-obvious branch links to hidden spaces.

### Hum Lines
- Low-frequency textual lines (single-sentence whispers).
- Behavior: Appear only during long-hover or revisit milestones.

## D. Branches (Nonlinear Paths)

The world is intentionally non-linear. Paths are conditional and can fork based on behavior.

### Branch Rules
- Branch by interaction type: hover path, click path, long-hover path, revisit path.
- Branch by season: current seasonal profile changes available nodes.
- Branch by unlock state: rare channel unlocks hidden chambers.

### Canonical Branch Graph
- Home -> Hub -> Pedals -> Galleries
- Ethos -> Root Archive OR Lantern Vault
- Learning Wheel -> Seasonal Alcove -> Storm Cabinet
- Mythology -> Fracture Pedal -> Storm Cabinet
- House and Garden -> Lantern Pedal -> Lantern Vault

## E. Shifts (Seasonal and Time-Based Changes)

Shifts alter both visual and systemic behavior.

### Seasonal Shift Model
- Spring/Fog: Lower speed, softer fades, cooler tones.
- Summer/Ocean: Higher shimmer frequency, brighter highlights.
- Autumn/Storm: Higher wobble variance, deeper contrast.
- Winter/Soil: Slower drift, longer life cycles, darker field.

### Time Shift Model (Session Time)
- 0-3 min: Orientation mode, fewer rare events.
- 3-8 min: Active mode, normal rare chance and branch density.
- 8+ min: Deep mode, hidden text frequency increases.

## F. Returns (Loops and Revisits)

Returns are first-class mechanics. Revisits should not repeat the same sky.

### Return Loop Rules
- Visit counter modifies constellation seed.
- Completed branch history biases next available branch options.
- Previously seen lore lines are deprioritized.
- After 3 visits, at least one new rare variant is guaranteed.

### Loop Rewards
- Return 2: New guide glyph behavior.
- Return 3: Persistent rare form in pool.
- Return 5: Unlock secret branch toward final hidden page.

## H. Page Themes Blueprint (Studio as Living Flower)

Each page is a pedal, season, room, and myth chamber. Every page should carry visible content plus a hidden Hub bridge.

### Ethos (Soil / Roots / Breath)
- Theme: Foundation, compost, ache, staying.
- Motif: Soil gradient, root lines, seed glyphs, dusk fade.
- Behavior: Slow breathing opacity and rising vine accents.
- Hidden Hub: Faint star in universe fade and drifting top glyph.

### Glyphs (Garden / Blossoms / Echoes)
- Theme: Symbols, blossoms, pressed myth, living system.
- Motif: Vine arcs, glyph blossoms, botanical geometry, shimmer pulses.
- Behavior: Glyph drift and hover-to-reveal meaning.
- Hidden Hub: Rare drifting glyph in upper corner and cosmic node behind archive grid.

### Learning Wheel (Seasons / Cycles / Weather)
- Theme: Spring fog, summer ocean, autumn storm, winter soil.
- Motif: Seasonal gradients, quadrant colors, circular geometry, weather glyphs.
- Behavior: Subtle wheel rotation and seasonal pulse fragments.
- Hidden Hub: Winter quadrant star and top-edge seasonal glyph reveal.

### Ledger (Hum / Lines / Resonance)
- Theme: Vibration, hum, resonance, pulse.
- Motif: Horizontal hum lines, faint oscillation, pulse glyphs.
- Behavior: Subtle line vibration with hover-revealed hum text.
- Hidden Hub: Pulse node at top-right and hum line pointing upward.

### Dialogues (Wind / Voice / Silence)
- Theme: Conversation, breath, silence, return.
- Motif: Wind lines, whisper glyphs, silence gaps.
- Behavior: Gentle text fade and expanding silence spacing.
- Hidden Hub: Silence node in upper fade and upward whisper drift.

### Mythology (Constellations / Arcs / Story)
- Theme: Cosmic lore, rare glyphs, mythic chambers.
- Motif: Starfield, cosmic arcs, drifting glyph constellations.
- Behavior: Star shimmer and arc pulse.
- Hidden Hub: Cosmic node with rare glyph star.

### House and Garden (Structure / Shelter / Growth)
- Theme: Home, garden, vine, soil, rooms.
- Motif: Vine-covered frame, soil texture, garden geometry.
- Behavior: Slight vine growth and seed pulse.
- Hidden Hub: Vine tip to sky and drifting seed glyph.

### Invitation (Dusk / Threshold / Welcome)
- Theme: Welcome, dusk, breath, arrival.
- Motif: Dusk gradient, soft glow, threshold line.
- Behavior: Glow pulse and slight dusk shift.
- Hidden Hub: Shimmer point and dusk star near top edge.

### Contact (Quiet / Night / Return)
- Theme: Quiet, night, return, presence.
- Motif: Night gradient, soft stars, quiet glyphs.
- Behavior: Hover-bright stars and quiet glyph pulse.
- Hidden Hub: Small upper-corner star and drifting quiet glyph.
